## Incident

Row-menu "Disable" on site 1 (Hohenheim Admin) fired `toggle_site` with no
confirmation (SiteResource.java:669) and took admin.starfleet.life offline
("404 - No site configured") for ~4 minutes (16:54-16:58 CEST). Recovered via
an ssh port-forward to 127.0.0.1:3000 and the same menu's Enable. Side effects
(released claim for admin.starfleet.life, site revisions #3/#4) lifted/harmless.

## Findings

Critical
1. Site Disable/Enable (row menu + record header) has no confirmation; can lock
   the panel out.

High
2. Keyboard Enter on a row-menu Delete navigates to the /delete page AND opens
   the modal; Escape leaves a live Delete page.
3. Env var Kind=Secret has no secret input; refusal leaks column semantics.
4. Validation re-render drops switch defaults, repeatable rows, Advanced state
   and the creating query param (site, domain, request, instance forms).
5. Access rule save after a validation failure is refused as a false
   "changed by someone else" conflict (stale revision token).
6. No cascade: deleting an access list orphans its rules; deleting a site
   orphans its domains (dangling site id) and the released claim shows "3".
7. Shell grid is sized by the sidebar, so the document scrolls; settings nav
   and Save bar never stick; System group below the fold at 1440x900.

Medium

   accepted; list action navigates to the record.
9. Clipping/overlap: 390 onboarding "Open" over titles, hostname truncation
   without ellipsis; 1024 stat tiles over icons; Hosts "Host" column clipped
   under pinned Actions; templates "Source" clipped.
10. Focus: path picker opens unfocused and drops focus per directory; rule
    toggle and env-var delete drop focus; inline editor reopens stale after
    Enter with no toast.
11. Return targets ignored for rule save/delete and domain add.
12. Rules copy vs behaviour: "starts switched off" but Group is On; refused
    value printed in heading/title; Move up/down enabled for one rule.
13. Generic confirmations (host, environment, access list, channel, rule) next
    to exemplary ones (site, zone, certificate, DNS record, lift quarantine).
14. Copy leaks: raw key match_count, "pruneByRetention()", "1 results",

15. Session revocation recovery is silent; failed login drops _return.
